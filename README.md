# Server, Virtualization & Mobile Dashboard Core

An enterprise-grade, single-file interactive server management, virtualization, and multi-device telemetry dashboard engineered and attributed to **CHHOUN DEVID**.

---

## 🚀 Key Features

* **120 FPS Live Telemetry & Shell Console**: Real-time server performance metrics, CPU/RAM/Network graphs, and an interactive root terminal multiplexer.
* **Virtualization & VM Management**: Deploy, configure, and monitor virtual machine nodes (Windows 11 Pro, CentOS 9, Ubuntu, Kali Linux, RHEL).
* **Software BIOS Flashing & Retro Themes**: Authentic retro BIOS color theme engine (Classic Award Blue, Green Phosphor, Amber CRT, Cyberpunk Cyan) with CRT scanline effects.
* **Domain Integration & SSH Routing**: Windows Domain joining (`NEXUS.CORP.LOCAL`), global server SSH root IP generation, and cross-server deployment.
* **Pixel-Based Binary & Screen Security**: Remote client screen lock with dual-admin approval gates (`Admin1` / `Admin2`) and target image/DNS follow-up tracking.
* **Cloud Database & Sync Workflows**: Automated asset ingestion (`.zip`, `.pdf`, `.img`, `.sound`, `.png`, `.7z`) with live backend sync workers and history logging.
* **Multi-Platform PWA Support**: Fully optimized responsive layouts for desktop, iPhone, and Android (including Dynamic Island safe-area support).
* **Development Studios**: Built-in Swift Program Studio and Frontend Program Studio for code compilation and project exports.
